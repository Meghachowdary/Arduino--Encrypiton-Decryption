# Arduino-Based Caesar Cipher Encryption and Decryption System

## 📌 Overview
This project implements a basic Encryption and Decryption System using **Arduino Uno** and the **Caesar Cipher Algorithm**. It demonstrates how plaintext is converted into encrypted text and then decrypted back to its original form.

## 🎯 Aim
To implement a basic encryption and decryption system using Arduino Uno and the Caesar Cipher algorithm to understand the fundamentals of cryptography and embedded systems.

## ✨ Features
- Encrypts text using Caesar Cipher (+3 shift)
- Decrypts encrypted text (-3 shift)
- Displays output on a 16×2 LCD
- Real-time simulation using Wokwi
- Arduino Uno based implementation

## 🛠 Components Used
- Arduino Uno R3
- 16×2 LCD Display
- Potentiometer
- Jumper Wires
- Wokwi Simulator

## 🧠 Algorithm
- Read input text
- Convert to uppercase
- Encrypt using +3 shift
- Display encrypted text
- Decrypt using -3 shift
- Display original text
